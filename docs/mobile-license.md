## 8. Разрешение на использование разрешений Android

8.1. Для корректной работы Приложение запрашивает следующие разрешения Android:

| Разрешение | Назначение |
|---|---|
| SEND_SMS | Отправка SMS-сообщений |
| READ_SMS | Чтение входящих SMS |
| RECEIVE_SMS | Получение уведомлений о входящих SMS |
| READ_CONTACTS | Синхронизация контактов |
| READ_PHONE_STATE | Определение статуса SIM-карты |
| FOREGROUND_SERVICE | Работа в фоновом режиме |
| INTERNET | Связь с сервером GoSMS |
