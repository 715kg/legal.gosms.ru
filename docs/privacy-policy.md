## 4. Принципы обработки

Оператор обрабатывает персональные данные в соответствии с принципами, установленными ст. 5 ФЗ-152:

- **Законность** — обработка осуществляется только при наличии правового основания.
- **Цель** — данные собираются для конкретных, заранее определённых целей.
- **Минимизация** — обрабатываются только те данные, которые необходимы для достижения заявленных целей.
- **Точность** — Оператор принимает меры для поддержания актуальности данных.
- **Ограничение срока хранения** — данные хранятся не дольше, чем требуется для целей обработки.
- **Конфиденциальность** — данные защищены от несанкционированного доступа, изменения, распространения и уничтожения.
